Output styles are the most underrated feature in Claude Code.

AGENTS.md is context your agent reads. An output style goes into the system prompt, so you get strict control over how it replies.

Agents are way too verbose by default. I only want what needs my attention, not paragraphs that bury it.

So I designed an output style for running lots of tasks in one thread:
→ every reply is a table of ongoing tasks and their status
→ anything that needs me is numbered at the end

Then I can reply: "1 yes. 2 yes. 3 elaborate. 4 ignore"

If I want to see the nitty gritty details I can just ask.
